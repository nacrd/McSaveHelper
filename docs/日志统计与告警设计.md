# 日志统计与告警设计

## 统计面板

- 今日总量：按本地自然日边界扫描 JSONL。
- 级别占比：DEBUG/INFO/WARN/ERROR/FATAL 使用五条原生 `QProgressBar`。
- 近 7 天趋势：使用 Qt `QPainter` 绘制折线，缺失日期补零，不依赖图表包。
- 异常聚合：按 SHA-256 指纹显示次数、模块、代表消息和最近出现时间。

统计在 Qt 线程池运行，结果包含覆盖范围；UI generation 变化时丢弃迟到结果。

## 告警规则

规则字段：名称、启用状态、级别、窗口分钟数、阈值、通知方式、冷却分钟数、邮件收件人。规则
原子保存到 `logs/alerts/rules.json`，触发历史追加到 `logs/alerts/history.jsonl`。损坏规则或历史行
被保守跳过，不阻止其他有效数据加载。

## 触发和通知

`QtAlertController` 每 5 分钟在线程池调用 `AlertService.check()`：

1. 按规则时间窗口流式扫描日期文件。
2. 数量达到阈值后检查同一规则冷却期。
3. 先构造不可变 `AlertEvent`，再调用系统或邮件通知端口。
4. 无论通知是否成功，都将结果和错误写入告警历史。

系统通知优先使用 `QSystemTrayIcon`，不可用时回退非模态 `QMessageBox`。邮件使用标准库 `smtplib`；
服务器、端口、用户名和发件人来自环境变量，密码只读取 `MCSAVEHELPER_SMTP_PASSWORD`，不会写入
QSettings、日志或规则文件。
