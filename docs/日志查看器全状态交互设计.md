# 日志查看器全状态交互设计

本文定义底部日志 Dock 的完整状态反馈。所有后台结果带 generation；筛选变化、关闭面板或应用
退出后，旧 generation 的结果直接丢弃。

| 状态 | 触发 | UI 反馈 | 可用操作 |
|---|---|---|---|
| 初始空状态 | 尚无 JSONL 记录 | “暂无日志，应用启动后将自动记录” | 筛选、告警配置 |
| 加载中 | 首次加载、筛选、统计 | 状态栏“加载中…”，表格保留旧内容 | 可修改条件或关闭面板 |
| 有结果 | 后台查询完成 | 表格替换为最多 300 条结果，更新今日统计和趋势 | 选择、复制、导出 |
| 无匹配 | 文件存在但条件无结果 | “无匹配日志”，筛选条件保持 | 修改筛选、清空条件 |
| 损坏行 | JSONL 某行无法解析 | 显示损坏行数量，其余有效记录继续显示 | 导出有效结果 |
| 实时开启 | 新日志成功落盘 | 100 ms 合并刷新并滚动到最新记录 | 关闭实时模式 |
| 实时关闭 | 新日志成功落盘 | 显示“有 N 条新日志”按钮，不改变当前滚动位置 | 点击按钮刷新 |
| 选中查看 | 点击表格行 | 详情区显示消息、extra、进程/线程和完整堆栈 | 复制选中日志 |
| 复制成功 | 剪贴板写入完成 | 状态栏短暂显示“已复制” | 继续浏览 |
| 导出中 | 选择导出路径 | 后台流式导出，界面不冻结 | 可继续浏览 |
| 导出完成 | 原子替换目标成功 | 显示导出条数 | 打开目标目录 |
| 清空确认 | 点击清空 | 模态确认“永久删除全部本地日志归档” | 确认或取消 |
| 存储降级 | JSONL 写入失败 | 显示“已切换紧急日志”持久警告 | 检查磁盘/权限 |
| 存储已满 | 清理后仍超软上限 | 显示“日志存储空间已满，请清理旧日志” | 清空日志 |
| 已释放 | Dock/应用关闭 | 停止计时器、保存 QSettings、丢弃迟到结果 | 无 |

颜色只用于辅助识别：DEBUG 灰、INFO 中性、WARN 黄、ERROR 红、FATAL 橙红；级别文本始终显示，
不能只靠颜色。加载、空结果和错误状态在固定状态栏位置呈现，避免表格布局跳动。
